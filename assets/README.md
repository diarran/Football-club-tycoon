# assets/

Ressources de développement du jeu : modèles exportés depuis Studio (`.rbxm`), images de référence,
icônes, maquettes d'interface.

- Les modèles 3D (tribunes, bâtiments, décor) peuvent être exportés depuis Studio avec
  clic droit > « Save to File… » puis rangés ici.
- Tout doit être **fictif** : pas de logos de vrais clubs, pas de vrais joueurs, pas de marques.
- Les données des joueurs ne sont jamais stockées ici : elles vivent dans les DataStores Roblox.
